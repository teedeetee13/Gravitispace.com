# Hữu Duyên

Kho chữ chữa lành về Tarot, Chiêm tinh và Tử vi. Lướt xuống, bài viết nào đến với bạn, là duyên.

- Mã nguồn website: [`web/`](web/) (xem [web/README.md](web/README.md))
- Tự động đăng lên GitHub Pages mỗi khi đẩy code lên nhánh `main`: [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)

Chạy thử trên máy:

```bash
python -m http.server 5173 --directory web
```
